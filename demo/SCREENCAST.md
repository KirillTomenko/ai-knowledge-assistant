# Запись экрана: 50–60 секунд

**Готовность:** сценарий подготовлен; запись успешного RAG пока заблокирована отсутствием ключей. Сначала выполните `python -m demo.run --live`, вручную проверьте ответы и источники. Если вопрос без ответа вызывает выдуманную сумму, покажите это как ограничение, не заменяйте ответ заранее подготовленным текстом.

Подготовка вне записи: открыть `http://127.0.0.1:8010/docs`, авторизоваться через Authorize (не показывать пароль); оба документа должны иметь статус `done`. Открыть TXT в соседнем окне. Развернуть `POST /api/v1/ask`, нажать Try it out. Не показывать `.env`, токены и панель авторизации.

| Время | Точные действия | Короткая подпись |
|---|---|---|
| 0–5 с | Показать заголовок Swagger и два учебных TXT | «Учебная компания “Север”. Поиск правил работы» |
| 5–17 с | В `/api/v1/ask` вставить JSON ниже, нажать Execute; дождаться ответа | «Вопрос сотрудника → поиск по документам» |
| 17–27 с | Выделить фактический `answer`, затем `sources[].source` и `excerpt` | «Ответ нужно сверить с источником» |
| 27–35 с | Перейти к `sever_remote_work.txt`, показать раздел 1 со сроком 16:00 | «Подтверждение в исходном документе» |
| 35–48 с | Вернуться в Swagger, заменить question на «Какую сумму компания компенсирует за домашний интернет?», нажать Execute | «Проверка вопроса без ответа в базе» |
| 48–58 с | Показать фактический ответ. При корректном отказе — выделить его; при ошибке — честно показать ошибку | «Отказ проверяем отдельно. Решение — за человеком» |

```json
{"question":"Сколько дней в неделю можно работать удалённо и когда нужно согласовать дни?","collection_name":"demo_sever_2026","use_mmr":false}
```

Время внешних API непредсказуемо. Если ожидание длинное, сократите его монтажом с подписью «ожидание сокращено»; не ускоряйте так, чтобы создать ложное впечатление измеренной скорости. Перефразированный вопрос из `questions.json` проверяется в отчёте и может быть показан отдельным дублем.

Если ключи не восстановлены: вместо постановочного ответа покажите `results.json` со статусом `blocked_missing_settings` и подписью «Подготовленный сценарий; ответы модели ещё не проверены». Такой ролик не демонстрирует работающий RAG end-to-end.
