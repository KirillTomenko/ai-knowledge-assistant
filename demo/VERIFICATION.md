## Исправленные препятствия

- Несовместимые pins SQLAlchemy/LangChain, httpx/Supabase, aiohttp и Pydantic/aiogram согласованы без смены архитектуры.
- Импорт асинхронного клиента Supabase переведён на существующий публичный экспорт SDK.
- У DELETE с HTTP 204 отключено автоматическое построение модели тела, ломавшее импорт FastAPI.
- Роутер коллекций использует существующий ленивый ChromaService: прежний legacy импорт создавал клиент ещё до старта API.
- Индексация сохраняет исходное имя документа для источников; UUID остаётся именем файла на диске.
- Исправлены ранняя настройка тестового окружения и адреса подмен Supabase; реальные ключи для тестов не используются.
- В Compose закреплена ChromaDB 0.5.20 и работающий Python heartbeat; удалён несуществующий Alembic COPY из API Dockerfile, боту добавлены используемые RAG-зависимости.

## Что остаётся

Восстановить в локальном `.env`: `OPENAI_API_KEY`, `SUPABASE_URL`, `SUPABASE_KEY`, `ADMIN_PASSWORD`. Проверить `OPENAI_BASE_URL`, доступность выбранных моделей, права ключа к таблицам и применить `sql/schema.sql` в тестовом проекте, если таблиц ещё нет. Для Telegram отдельно нужен `TELEGRAM_BOT_TOKEN`. Прокси — только при необходимости с реальным адресом. `DATABASE_URL` и `API_SECRET_KEY` текущая цепочка не использует.

Затем перезапустить API, выполнить `python -m demo.run --live` и проверить три фактических ответа вручную. Семантический поиск, правильность перефразированного ответа, отказ на непустой базе и доступ к живой Supabase ещё не проверены. Полная сборка Docker API/бота, Telegram, PDF/DOCX и binary DOC не проверялись в выбранном сценарии. В API нет доказательства, что каждый возвращённый источник подтверждает ответ, и нет ссылок на скачивание оригинала.

**Статус итерации:** локальная подготовка, исправления запуска, учебные материалы и автоматические проверки завершены. End-to-end демонстрация и запись успешного RAG **не завершены** из-за отсутствия настроек. Нельзя заявлять клиентское внедрение, точность, экономию времени или готовность к промышленной эксплуатации.
